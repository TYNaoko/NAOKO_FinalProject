•What is the creative motivation / intended use of your project.
(Why did you make it? Who do you envision using it? What do you want
the audience to experience?)

This year I wanted to do more work relating to disability as I myself have a hearing impairment I naturally gravitated to creating a piece of work using sign language. I only became hard of hearing 2yrs ago so I still struggle with accepting my disability so I have been thinking if I should learn sign language incase my hearing deteriorates. I created this as an introduction to SGSL so it would not feel scary, I wanted the design choices to feel vibrant and bold as it frames my face as if to confront my own self-acceptance. Through out the project I found how fun learning SGSL was, it was satisfying getting the signs right. I hope for hearing people to use it to learn local slang to communicate with hard of hearing people, I think people are not confident with communicating with a hard of hearing person so if they could learn the signs, it can break down communication walls. After aren't we all Singaporean? 

• Describe how you implemented the project.
(What generative techniques have you used, and why? What other
software tools or libraries did you use?)

I used the week 6 TrainOwn project heavily as the foundation for the work. Just slightly modifying it by adding more classes and a trigger to overlay the designs. The base of the trainown code encapsulated my concept well so I did not have to use other weeks exercises.  


• How successful was your project in meeting your creative aims.
(What works well? What challenges did you face? What might you change
if you had more time?)

I would say I am satisfied with the outcome. It is satisfying when the right overlays are triggered though I did struggle trying to capture signs that require both hands, I had to get help from family to click the capture button in teachable machine and I think adding a separate learning website ties the work nicely. At first I was not sure how I wanted it to be executed but I am glad I got inspiration from early 2010s learning websites which made me want to use that format.
